# 🎮 OpenWii — Hammas Edition

A browser-based multiplayer gaming platform where a **PC/laptop runs the game** and a **smartphone can be used as a wireless controller**.

## 🚀 Play OpenWii

### 🎮 Open the Game

**[▶️ Play OpenWii Live](https://openwii-hammas.onrender.com/)**

### 📱 Open the Mobile Controller

**[📱 Open Mobile Controller](https://openwii-hammas.onrender.com/controller)**

The PC and phone connect through the OpenWii server.

---

## 🕹️ Games

OpenWii includes multiple browser games, including:

* 🏎️ Mario Kart
* 🍉 Fruit Ninja
* 👽 Alien Attack
* 🎯 Shooting Range
* 🏌️ Golf
* 🏝️ Island Flyover
* ⚔️ Swordplay
* 🏓 Table Tennis
* 🎨 Drawing
* ❌⭕ Tic-Tac-Toe

More games can be added to the platform.

---

## 📱 Smartphone Controller

The smartphone controller is designed to provide:

* 🎮 Virtual buttons
* ⬆️⬇️⬅️➡️ Direction controls
* 📱 Motion/orientation controls
* 🔄 Controller calibration
* 📳 Game feedback
* 🌐 Wireless connection through the OpenWii server

The controller is accessed from:

**https://openwii-hammas.onrender.com/controller**

---

## 🖥️ How to Play

### 1. Open OpenWii

On your computer, open:

**https://openwii-hammas.onrender.com/**

### 2. Open the Controller

On your smartphone, open:

**https://openwii-hammas.onrender.com/controller**

### 3. Connect

Keep the game open on the computer and the controller open on the phone.

### 4. Choose a Game

Select a game from the OpenWii game launcher.

### 5. Play

Use the keyboard, mouse, or smartphone controller depending on the game.

---

## 🛠️ Technology

OpenWii is built using web technologies including:

* JavaScript
* HTML5
* CSS3
* Node.js
* Express.js
* Socket.IO
* Web APIs
* Smartphone motion/orientation APIs
